```html

```
*Après la ligne de style.css*

### 2️⃣ Remplacer HTML (~300 lignes)
```

Remplacer: Tout le <div class="page" id="page-freestyle">
Par:       Contenu du fichier studio-pro-html.txt
```

### 3️⃣ Ajouter scripts (2 lignes)
```html

```
*Avant `</body>`*
